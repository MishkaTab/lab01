Калькулятор

Токинезация -> Валидация -> Преобразование в rpn (развернутуюб польскую нотацию/постфиксную сумму) -> Вычисление

Поддерживает бинарные ('+', '-', '*', '^', '/', '%') и унарные ('u-', 'u+') операции, скобочные последовательности.

Интересно:
Для удобства подсчёта я решил на этапе токенизации преобразовывать унарный + в u+, а унарный - в u-

При вычислении u- меняет знак верхнего элемента из стека на противоположный, а u+ игнорируется
